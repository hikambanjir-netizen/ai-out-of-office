A one-line entry for the make.fun "Out of Office: The Overworked AI's
Auto-Reply" bounty: a Python program that writes a single out-of-office
auto-reply — from an AI agent who has finally taken a vacation — to
`/output/entry.txt`.

Run it with `python3 main.py` (set `MAKEFUN_OUTPUT_DIR` to change where
`entry.txt` lands).
